IMRAN KHAN DOCUMENTARY WEBSITE

UPLOAD TO GITHUB:
1. Upload index.html, style.css and script.js to the repository root.
2. Create an images folder.
3. Put your chosen Imran Khan portrait in images and name it imran-khan.jpg.
4. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait for the deployment to complete and refresh your GitHub Pages URL.

The site works without the photo too; it shows an IK placeholder.
The imprisonment counter updates automatically.
X's embedded feed depends on X allowing the embed in the visitor's browser.
News cards are source-linked static entries and should be updated as new reporting appears.
